# Upgrade

:::info

This document provides the upgrade path principles and supported version compatibility for Alauda Container Platform Cluster Authentication.

:::

## Compatibility Matrix

The table below lists supported versions of the Alauda Container Platform Cluster Authentication:

|Cluster Authentication Plugin Version|Supported Alauda Container Platform Version|
|---|---|
|1.0.x|4.2.x|

## Upgrade Path Guidelines

### Patch-Level Upgrade
- **Description**: Upgrades between any patch versions within the same minor version are fully compatible and can be performed directly.
- **Example**: 1.0.0 → 1.0.1
